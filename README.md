# BakbakHosting

BakbakHosting is a full-stack, self-hosted Minecraft server management panel. It lets you spin up Paper servers in a few clicks, then control them from a web dashboard with a live console, start/stop controls, and an in-browser file manager. Server creation, jar downloads, EULA acceptance, and port assignment are fully automated, with real-time progress streamed to the browser over WebSockets.

---

## ✨ Features

- **One-click server creation:** pick a server ID, display name, Minecraft version, and RAM allocation (1–6 GB).
- **Automatic setup:** fetches the latest Paper build for the selected version from the PaperMC API, downloads the server jar, accepts the EULA, and assigns a unique port.
- **Live setup progress:** download and setup progress is streamed to the client in real time through Socket.IO.
- **Server overview:** all servers are listed and grouped as active or inactive.
- **Live console:** streams server output to the browser as it happens (with ANSI color codes stripped) and sends commands straight to the server process.
- **Lifecycle controls:** load, start, and stop servers from the dashboard.
- **File manager:** browse a server's directory tree, open text files (such as `server.properties`), edit them in the browser, and save changes.

## 📁 Repository Structure

This monorepo contains both parts of the platform:

```text
.
├── backend/                  # Node.js + Express + Socket.IO API and server process manager
└── bakbakhosting-dashboard/  # React + Vite web dashboard
```

### 1. `backend/` — API & Server Manager

A **Node.js** service built with **Express 5**, **TypeScript**, and **Socket.IO**.

- Spawns and supervises Minecraft server processes (Java child processes with configurable heap size).
- Pipes server stdout to subscribed dashboard clients over WebSockets and keeps a rolling buffer of recent log lines.
- Forwards console commands from the dashboard to each server's stdin.
- Integrates with the **PaperMC Fill API (v3)** to list available versions and resolve download links for the latest builds.
- Stores server metadata (ID, name, version, RAM) and port allocation state in **SQLite**.
- Exposes REST endpoints for listing servers, browsing directories, and reading/writing files.

### 2. `bakbakhosting-dashboard/` — Web Dashboard

A **React 19** single-page application built with **Vite**, **TypeScript**, and **Tailwind CSS 4**.

- Server list page with active/inactive status indicators.
- New server wizard with version selector, RAM slider, and a live progress overlay.
- Per-server dashboard with Status, Console, and File Manager tabs, routed with **React Router 7**.
- Shared Socket.IO connection per server, provided to all tabs via React Context.
